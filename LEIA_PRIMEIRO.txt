MotoPRO - Fase 1 completa (frontend e backend)
=================================================
frontend-MotoPRO: Next.js 15, deploy na Vercel
backend-MotoPRO: Node.js/Express, deploy no Heroku

Publicação:
1. Publique o backend no Heroku e valide /api/health.
2. Na Vercel, configure API_INTERNAL_URL com a ORIGEM HTTPS real
   do backend, sem /api e sem barra final (Preview e Production).
3. Faça Redeploy do frontend depois de definir a variável.
4. No Heroku, APP_ORIGIN deve ser a origem HTTPS real da Vercel.
5. Homologue assinaturas, Rappidex, login e cortesias.
6. Execute npm ci, npm run typecheck e npm run build
   em cada pasta antes de substituir a produção.

ATENÇÃO: o build do frontend agora funciona sem API_INTERNAL_URL,
mas as rotas /api/* retornam 503 enquanto ela não for configurada.
Não copie senhas, tokens nem .env de produção para este pacote.
